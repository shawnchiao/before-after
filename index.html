I built Lingofloat — an AI language-learning platform — alone: React front end, Node + BullMQ backend, AI pipelines, iOS release. A few hundred learners use it. You asked for before/afters first, so here they are.

BEFORE / AFTER

Three screens that bothered me

Drag the handle. Everything on the “after” side shipped to production.

01

The login was someone else’s template

Stock Auth0: a white template card floating in a void, link colors that belonged to no palette, the logo squeezed into a tiny box. It was the first screen every user saw — and it said nothing about the product.

BeforeAfter
  • A split layout gives the brand a side of its own — wordmark, breathing room, one hairline rule.
  • The form sits on frosted glass over an ambient gradient, so signing in feels like part of the product, not a detour through a vendor.
  • One mint gradient is reserved for the single primary action; everything else steps back to outline weight.
02

A transcript is not a log file

The player is the product, but it read like terminal output: every sentence at equal weight, controls crowded into a strip welded to the bottom edge of the screen.

BeforeAfter
  • The controls became a floating pill on an artwork-tinted stage — the screen feels like listening, not scrubbing.
  • The current sentence carries full contrast while past and upcoming lines fall back, so your eye always knows where the audio is.
  • Per-sentence actions (replay, analyze) live at the timestamp — where your cursor already is.
03

Two themes fighting on one screen

Light cards pasted onto a dark shell, a search bar from a different app, tabs in three styles. Each piece was fine on its own; together, it was noise.

BeforeAfter
  • One dark surface system: cards, tabs, search and nav share the same material, radius and border logic.
  • Artwork is now the loudest thing in the grid — because nothing else is shouting.
  • Search took center stage with quiet filter pills; the chrome got out of the way.

UNDER THE HOOD

The parts you can’t screenshot

Frontend
A word-level interactive audio player: auto-pause at sentence ends, one-tap repeat, and select any span of the transcript to replay exactly that audio. Precise audio–text syncing under a UI polished enough to be the product’s differentiator.
Backend
A BullMQ job system managing outbound API concurrency, with retry and error-handling strategies that keep audio processing reliable at scale.
AI workflows
A custom practice-session pipeline — prompt engineering, FFmpeg audio processing, and defensive engineering around LLM and API failures — turning learner-selected content into tailored practice sessions.
Ingestion
A production audio-ingestion pipeline (yt-dlp, FFmpeg, proxy routing) engineered to keep sourcing content despite aggressive bot detection — a hard operational problem the product depended on.
Web
A Next.js landing page in 18 languages, server-rendered for SEO.
Mobile
Migrated the React web app to iOS with Capacitor with minimal rework — and got it through App Store review.
